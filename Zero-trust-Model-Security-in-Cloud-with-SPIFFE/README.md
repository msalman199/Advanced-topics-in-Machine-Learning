## 🎯 Overview

This lab demonstrates how to implement **Zero-Trust security** in a cloud-native environment using **SPIFFE** and **mTLS**. You learn the Zero-Trust and SPIFFE principles, set up SPIFFE to issue identities and certificates to services, secure machine learning services with mTLS using SPIFFE IDs for service authentication, and integrate SPIFFE with **Kubernetes** to enforce Zero-Trust policies for ML model deployment.

| 🎓 Learning Objective | 🛠️ Tool / Technology |
|---|---|
| Understand Zero-Trust principles | Zero-Trust, SPIFFE |
| Issue identities and certificates to services | SPIFFE |
| Authenticate ML services | mTLS with SPIFFE IDs |
| Enforce Zero-Trust for ML deployment | Kubernetes |

## 📚 Key Concepts

| 🔑 Concept | 📝 Description |
|---|---|
| **Zero-Trust Security** | Security model that authenticates services rather than assuming trust |
| **SPIFFE** | Framework for issuing identities and certificates to services |
| **SPIFFE ID** | Identity used for service authentication |
| **mTLS** | Mutual TLS, where both sides of a connection authenticate each other |
| **Service Identity / Certificates** | Credentials issued to services in a cloud-native environment |
| **Kubernetes Integration** | Applying SPIFFE to secure communication in Kubernetes |
| **Secure ML Deployment** | Protecting machine learning models and their data in distributed systems |
