## 🎯 Overview

This lab walks through preparing a **secure Linux environment for advanced machine learning**. You set up Python, Jupyter, and essential ML libraries (**TensorFlow**, **PyTorch**, **Scikit-learn**), secure the Jupyter Notebook server with **password protection and HTTPS**, and test the environment to confirm it is ready for advanced ML work.

| 🎓 Learning Objective | 🛠️ Tool / Technology |
|---|---|
| Configure a secure Linux environment | Linux |
| Set up Python, Jupyter, and ML libraries | Python, Jupyter, TensorFlow, PyTorch, Scikit-learn |
| Secure the Jupyter Notebook server | Password protection, HTTPS |
| Verify the environment works correctly | Environment testing |

## 📚 Key Concepts

| 🔑 Concept | 📝 Description |
|---|---|
| **Secure Linux Environment** | A Linux system configured so ML work runs in a safe, isolated setting |
| **Jupyter Notebook** | Interactive web-based environment for running and documenting ML code |
| **TensorFlow / PyTorch** | Deep learning frameworks used for advanced machine learning |
| **Scikit-learn** | Library for classical machine learning algorithms |
| **Password Protection** | Restricts access to the Jupyter server to authorized users |
| **HTTPS** | Encrypts traffic between the browser and the Jupyter server |
| **Environment Testing** | Verifying the installed stack works before starting ML projects |
