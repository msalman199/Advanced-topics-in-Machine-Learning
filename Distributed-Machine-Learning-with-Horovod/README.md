## 📖 Overview

This lab provides hands-on experience with **Horovod** and the core concepts of **distributed training** in deep learning. You set up Horovod to enable parallel training across multiple nodes or GPUs, adapt a **TensorFlow** model to train in a distributed manner, monitor and optimize training with **TensorBoard** and **learning rate scaling**, and save and load the trained model for inference.

---

## 🎯 Key Accomplishments

In this lab, you:

| # | ✅ Accomplishment | 🛠️ Area |
|---|------------------|---------|
| 1 | Set up **Horovod** for distributed deep learning, enabling parallel training across multiple nodes or GPUs | Environment Setup |
| 2 | Adapted a deep learning model (using **TensorFlow**) to train in a distributed manner using Horovod | Distributed Training |
| 3 | Monitored performance and optimized the training process with **TensorBoard** and **learning rate scaling** | Monitoring & Optimization |
| 4 | **Saved and loaded** the trained model for inference | Model Persistence |

## 🔑 Key Concepts

| 🏷️ Concept | 📝 Description |
|-----------|---------------|
| **Horovod** | Framework that scales deep learning models across multiple GPUs or machines |
| **Distributed Training** | Training a model in parallel across multiple nodes or GPUs |
| **Learning Rate Scaling** | Adjusting the learning rate to optimize the distributed training process |
| **TensorBoard** | Tool used to monitor training performance |
| **Model Saving/Loading** | Persisting the trained model so it can be loaded for inference |
