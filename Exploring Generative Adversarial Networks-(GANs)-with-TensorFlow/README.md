## 🎯 Overview

This lab introduces **Generative Adversarial Networks (GANs)**. You build theoretical understanding of how GANs work, implement a basic GAN in **TensorFlow** with a **generator** and a **discriminator**, train it on the **MNIST dataset** to generate handwritten digits, evaluate the model, and visualize the generator's output.

| 🎓 Learning Objective | 🛠️ Tool / Dataset |
|---|---|
| Understand how GANs work | Theory |
| Implement a generator and a discriminator | TensorFlow |
| Train and evaluate the GAN | MNIST dataset |
| Visualize generated images | Trained generator output |

---

## ✅ Key Accomplishments

In this lab, you:

- 📖 **Gained a theoretical understanding** of Generative Adversarial Networks (GANs) and how they work
- 🏗️ **Implemented a basic GAN using TensorFlow**, including a generator and a discriminator
- 🔢 **Trained the GAN model on the MNIST dataset** to generate handwritten digits and evaluated the model
- 🖼️ **Visualized the generated images** to see the output of the trained generator

## 📚 Key Concepts

| 🔑 Concept | 📝 Description |
|---|---|
| **GAN** | Generative Adversarial Network, a model that learns to generate new data |
| **Generator** | The network that produces generated images |
| **Discriminator** | The network that evaluates images in the GAN |
| **TensorFlow** | Framework used to implement and train the GAN |
| **MNIST Dataset** | Dataset of handwritten digits used for training |
| **Model Evaluation** | Assessing the trained GAN after training |
| **Output Visualization** | Viewing the generated images to inspect the trained generator |
