## 📖 Overview

This lab shows how to leverage state-of-the-art NLP models with **HuggingFace** and **Flask**. You install and configure the HuggingFace Transformers library, **fine-tune BERT** on the **IMDb dataset** for sentiment analysis, and **deploy the fine-tuned model as a Flask web service** that serves predictions.

---

## 🎯 Key Accomplishments

In this lab, you:

| # | ✅ Accomplishment | 🛠️ Area |
|---|------------------|---------|
| 1 | Installed and configured the **HuggingFace Transformers** library | Environment Setup |
| 2 | **Fine-tuned** a transformer model (**BERT**) on the **IMDb dataset** for sentiment analysis | Model Fine-Tuning |
| 3 | **Deployed** the fine-tuned model as a **Flask web service** to serve predictions | Model Deployment |
| 4 | Learned how to use **Flask** to integrate NLP models into real-world applications | Application Integration |
