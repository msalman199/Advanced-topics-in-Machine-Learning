## 🎯 Overview

This lab covers deploying a machine learning model in a **cloud-native environment**. You containerize a trained **TensorFlow** model with **Docker**, serve its predictions through a **Flask API**, configure a **Kubernetes deployment and service** for scalable serving, and deploy everything on a **Minikube** cluster, then access the model API for predictions.

| 🎓 Learning Objective | 🛠️ Tool / Technology |
|---|---|
| Containerize a trained model | Docker, TensorFlow |
| Serve model predictions | Flask API |
| Configure scalable serving | Kubernetes deployment and service |
| Deploy and test on a cluster | Minikube |

---

## ✅ Key Accomplishments

In this lab, you:

- 🐳 **Containerized a trained TensorFlow model** using Docker
- 🌐 **Set up a Flask API** to serve the model's predictions
- ☸️ **Configured a Kubernetes deployment and service** to deploy the containerized model for scalable serving
- ✅ **Successfully deployed the model on a Kubernetes cluster using Minikube** and accessed the model API for predictions

## 📚 Key Concepts

| 🔑 Concept | 📝 Description |
|---|---|
| **Containerization** | Packaging the trained model and its serving code into a Docker container |
| **Docker** | Tool used to build the container for the TensorFlow model |
| **Flask API** | Web API that serves the model's predictions |
| **Kubernetes Deployment** | Defines how the containerized model runs on the cluster |
| **Kubernetes Service** | Exposes the deployed model so the API can be accessed |
| **Minikube** | Local Kubernetes cluster used to deploy and test the model |
| **Cloud-Native ML Serving** | Deploying ML models with Docker and Kubernetes for scalability and flexibility |
