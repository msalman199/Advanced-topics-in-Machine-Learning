## 🎯 Overview

This lab shows how to use **Apache Airflow** to automate an end-to-end **machine learning pipeline**. You install and configure Airflow, design a **DAG** covering data ingestion, preprocessing, model training, and evaluation, and use **PythonOperator** to define tasks and set up dependencies for a complete workflow.

| 🎓 Learning Objective | 🛠️ Tool / Technology |
|---|---|
| Install and configure Airflow | Apache Airflow |
| Design an ML pipeline DAG | Airflow DAG |
| Define tasks and dependencies | PythonOperator |
| Automate ingestion, preprocessing, training, evaluation | End-to-end ML workflow |

---

## ✅ Key Accomplishments

In this lab, you:

- 📦 **Installed and configured Apache Airflow** on your machine
- 🧩 **Designed an Airflow DAG** to automate an end-to-end machine learning pipeline, including data ingestion, preprocessing, model training, and evaluation
- 🔗 **Used PythonOperator** to define tasks and set up dependencies for a complete workflow

## 📚 Key Concepts

| 🔑 Concept | 📝 Description |
|---|---|
| **Apache Airflow** | Platform for automating, scaling, and monitoring workflows |
| **DAG** | The workflow definition that organizes tasks and their dependencies |
| **PythonOperator** | Operator used to define tasks as Python functions |
| **Task Dependencies** | The ordering that links pipeline stages into a complete workflow |
| **Data Ingestion** | Pipeline stage that brings in the data |
| **Preprocessing** | Pipeline stage that prepares the data for training |
| **Model Training and Evaluation** | Pipeline stages that train the model and assess it |
